## 2. 🔍 GPU 하드웨어 가속 심층 분석 및 핵심 인사이트

### 1) ⚡ 순수 비디오 디코딩 성능의 압도적 개선 (GPU 전용 ASIC 엔진)
- **H.264 (2592x1520)**: CPU `5.98 ms` $\rightarrow$ **GPU `0.77 ms` (7.8배 단축)**
- **H.265 (2592x1520)**: CPU `10.71 ms` $\rightarrow$ **GPU `0.76 ms` (14.1배 단축)**
- **특징**:
  - H.264와 H.265 모두 GPU 전용 비디오 디코더 ASIC(NVDEC/Intel QuickSync/AMD VCN)을 통과하므로, **코덱의 복잡도와 무관하게 1ms 미만(0.76ms)의 초고속 디코딩**이 이루어집니다.
  - **호스트 CPU 연산 점유율이 0%로 감소**하여 라이다 PCD 데이터 처리 및 AI 객체 인식 연산에 CPU 자원을 온전히 할당할 수 있습니다.

### 2) 💡 VRAM $\rightarrow$ System RAM PCIe 전송 오버헤드 분석
- GPU에서 디코딩된 프레임(Direct3D 11 Surface)을 CPU 호스트 메모리로 복사(`av_hwframe_transfer_data`)할 때 PCIe 버스 대역폭 및 드라이버 동기화로 인해 약 `7.3 ~ 7.8 ms`가 소요됩니다.
- **결론 및 최적 운영 가이드**:
  - **4분할 그리드 화면 (서브스트림 800x448)**: CPU 디코딩 시간이 워낙 짧으므로(0.85ms), PCIe 복사 오버헤드가 없는 **CPU 소프트웨어 디코더가 가장 빠르고 효율적(1.07ms)**입니다.
  - **1채널 확대 초고화질 모드 (2592x1520 H.264 / H.265)**: CPU 코어 과부하를 방지하고 CPU 점유율을 0%로 유지하기 위해 **GPU 하드웨어 가속(D3D11VA)**을 활성화하면 디코딩 연산 부하가 완벽히 오프로드됩니다.

## 3. 세부 성능 변천사 (전체 최적화 이력)

```
[ 초기 상태: 4채널 profile2 H.264 ] 
  • 2592x1520 4개 동시 디코딩 (총 ~58ms / frame) ──▶ CPU 병목 발생
                              │
                              ▼ (1단계: 저해상도 서브스트림 도입)
[ Phase 1: 4분할 profile10 (640x480) ] 
  • 지연 1.98ms로 단축했으나 15fps 제한 및 4:3 화면 왜곡 발생
                              │
                              ▼ (2단계: 와이드 서브스트림 + 초저지연 옵션)
[ Phase 2: 4분할 profile4 + 1채널 profile2 ⭐ ] 
  • profile4 (800x448 @ 35.6fps) ──▶ 1.07ms 초저지연 & 16:9 완벽 비율
  • profile2 (2592x1520 @ 35.6fps) ──▶ 8.14ms 400만 화소 초고화질
                              │
                              ▼ (3단계: H.265 프로파일 벤치마크)
[ Phase 3: H.265 profile5 / profile3 측정 ] 
  • profile5 (800x448) ──▶ 1.80ms
  • profile3 (2592x1520) ──▶ 12.71ms (CPU 연산량 1.7배 증가 확인)
                              │
                              ▼ (4단계: GPU 하드웨어 가속 구현 및 측정 ⭐)
[ Phase 4: GPU D3D11VA 가속 구현 ] 
  • H.264 2592x1520 디코딩: 5.98ms ──▶ 0.77ms (7.8배 가속)
  • H.265 2592x1520 디코딩: 10.71ms ──▶ 0.76ms (14.1배 극적 가속, CPU 점유율 0%)
```

## 4. Latency 최적화 핵심 기법 총정리

1. **동적 프로파일 분기 (Dynamic RTSP Profile Switching)**: 4분할 시 `profile4`(1.07ms) $\leftrightarrow$ 1채널 확대 시 `profile2`(8.14ms)
2. **FFmpeg 초저지연 프로빙 (`nobuffer`, `low_delay`, `probesize=64KB`, `analyzeduration=100ms`)**
3. **GPU 하드웨어 가속 디코더 파이프라인 탑재 (`D3D11VA` / `DXVA2`)**
4. **마지막 프레임 유지 (Seamless Freeze Transition)**: 전환 시 블랙아웃/깜빡임 0초화
5. **스케일러 컨텍스트 캐싱 및 버퍼 재활용**: 메모리 할당 오버헤드 제거
