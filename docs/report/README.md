# 프로젝트 결과보고서 (초안)

`docs/SPATIAL-VMS_결과보고서_초안.pptx` 를 만드는 스크립트.

내용은 이 저장소의 커밋 내역(2026-08-03 ~ 08-19, 52건)과 루트 `README.md` 에서
뽑았다. 기획안 원문·회의록·팀 명단은 저장소에 없어서, 그 자리는 `○○○` 나
"확인 필요" 로 남겨 두었다 — 슬라이드 9(팀 구성), 10(일정), 16(피드백 출처),
18(자체 평가 점수) 가 해당한다.

목차는 배포된 결과보고서 양식(01 개요 / 02 팀 구성 / 03 수행 절차 / 04 수행 경과 /
05 자체 평가)을 그대로 따르고, 디자인만 앱의 관제실 다크 테마(`src/Theme.h`)
색으로 바꿨다.

```bash
npm install pptxgenjs      # 1회
node docs/report/build_report.js
```
