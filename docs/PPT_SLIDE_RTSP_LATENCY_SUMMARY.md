| 지표 (해상도) | 최적화 전 (기본/CPU) | 최적화 후 (하이브리드 GPU 가속) | 속도/성능 향상 배수 |
| :--- | :---: | :---: | :---: |

## 💡 4. [발표용 핵심 스크립트] 3줄 요약

1. **400만 화소 14.1배 초고속 GPU 가속**:
   - `2592x1520` 초고해상도 스트림 디코딩을 전용 GPU ASIC(D3D11VA)으로 처리하여 **10.71ms $\rightarrow$ 0.76ms로 14.1배 가속**하고 CPU 점유율을 0%로 오프로드했습니다.
2. **4분할 그리드 1.07ms 최저지연 달성**:
   - 저해상도(`800x448`) 4채널 동시 표출 시에는 PCIe 복사 오버헤드가 없는 CPU 디코딩을 채택하여 **1.07ms의 실시간 최저지연**을 구현했습니다.
3. **0초 무중단 백그라운드 웜업 스왑**:
   - 4분할 $\leftrightarrow$ 1채널 확대 전환 시 영상 멈춤(Freeze)을 0초화하여 사용자 경험을 극대화했습니다.
